Q1 : plantUMLでLoopの横に文字を書きたい。
A1 : gemini
PlantUMLのシーケンス図で`loop`の横（あるいは枠内）に文字を書きたい場合、主に**2つの方法**があります。状況に合わせて使い分けてみてください。

---

### 方法1：`loop` の直後にスペースを空けて書く（標準的な方法）

一番シンプルでよく使われる方法です。`loop` というキーワードの直後に**半角スペース**を空けてテキストを書くと、ループのタイトルとして表示されます。

```plantUML
@startuml
ユーザー -> サーバー : 処理開始

loop 10回繰り返す（ここに文字を書く）
    サーバー -> データベース : データ取得
    データベース --> サーバー : レスポンス
end

@endum

```

### 方法2：改行や詳細な説明を入れる場合

ループのタイトル部分に、より長い説明や改行を入れたい場合は、`[ ]`（ブラケット）を使って条件や詳細を囲むこともできます。

```plantUML
@startuml
ユーザー -> サーバー : 処理開始

loop データの同期処理
    [未送信のデータがなくなるまで\n条件をここに詳しく書けます]
    サーバー -> データベース : 同期実行
    データベース --> サーバー : 完了
end

@endum

```

---

### 💡 ちょっとしたコツ：枠の見た目を変えたい場合

もし「ループの条件（横の文字）」をもっと目立たせたい、あるいは枠線の色を変えたい場合は、以下のように `skinparam` を使うとおしゃれになります。

```plantUML
@startuml
' ループの枠線の色や背景色をカスタマイズ
skinparam SequenceGroupBodyBackgroundColor #FFFEE0
skinparam SequenceGroupHeaderBackgroundColor #FFD700

loop サーバーが応答するまでループ
    ユーザー -> サーバー : リクエスト
    サーバー --> ユーザー : タイムアウト
end
@endum

```

やりたい表現に合わせて試してみてください！
